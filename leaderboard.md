# Leaderboard

[View the RealControlBench leaderboard](https://aslcai.github.io/realcontrolbench/).

## Submit a method

Submit your method through a pull request to this repository. The RealControlBench team reviews the materials, runs the evaluation, and updates the leaderboard.

Include:

- **Method information:** method name, short description, and authors. Institution and paper URL are optional.
- **Implementation:** a GitHub repository or downloadable code archive, with a fixed commit SHA, release tag, or archive checksum.
- **Run instructions:** dependencies, required configuration, and the command to run your method. Include links to additional artifacts when needed.

To submit:

1. Open the leaderboard and click **Submit via GitHub**. Sign in to GitHub.
2. Fill in the prefilled submission file under `submissions/`.
3. Propose the file on a new branch, or in a fork when prompted, and open a pull request to `MingyuJ666/ControlBench:main`. Use a title such as `Submit method: <method name>`.

The submission is complete when the PR is open. Review and any requests for clarification take place in that PR. Evaluation and publication are performed by maintainers.
